For this assignment I used lists, sets, loops, functions, intersections, and sorting to create the product recommendation program. I first used a list to store the customer preferences because the program asks the user to enter their preferences one at a time. After the user is finished I converted the list into a set. I did this because sets remove duplicates so if someone enters the same preference more than once it will not be counted multiple times.

I also converted the product tags into sets because I needed an easier way to compare them with the customer preferences. In the count_matches() function I used intersection to find which tags the product and customer have in common. Then I used len() to count how many matches there were. The recommend_products() function goes through the products using a loop, checks how many tags match, and only adds products that have at least one match. After that the results are sorted so the products with the most matches show up first.

If there were 1,000 or more products the program could take longer because it currently checks every product in the list. Sets would still be useful for comparing the tags, but for a much larger program I would probably store the products in a database or organize them by their tags. That could make it easier to find matching products without going through every product each time.
